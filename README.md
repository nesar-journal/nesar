# NESAR

## Setup

```shell
# Disable telemetry (run once)
npm run disable-telemetry
```

## Development

```shell
# Spins up the development server
npm run dev

# Open development site
open http://localhost:3000
```

## Deployment

```shell
# Deploy app to Vercel
git push origin master
```
